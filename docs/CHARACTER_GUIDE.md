# 人物制作规范 (2.0 版)

本文档定义了项目中所有像素人物角色的设计标准与动画规范。

## 1. 基础尺寸与格式

- **画布尺寸**: 32x32 像素网格。
- **美术风格 **:
  - **头部**: 大，占主体约 4/10，强调五官、发型细节。
  - **身体**: 大，比头部略大。
  - **四肢**:
    - **手部**: **独立悬浮**的圆球/方块，不与身体连接。**必须**在模板中用特殊字符（如 `H`）标记手部位置（作为枪支挂载点）。
    - **腿部**: 极小或省略，主要通过身体浮动或简单的脚部色块表现移动。
- **方向**: 支持 **8个方向** (N, NE, E, SE, S, SW, W, NW)。
  - 为了节省资源，通常制作 5 个方向 (S, SE, E, NE, N)，其余通过镜像生成。
- **文件格式**: JavaScript 数组导出。

## 2. 细节要求

- **面部**: 必须清晰刻画眼睛（高光）、表情。
- **手部 (Mount Point)**: 每一帧必须包含手部字符，该字符不仅用于渲染手的颜色，还将被系统解析为枪支的渲染坐标。
- **附属物**: 头巾、围巾、头发等必须随动作大幅飘动。

## 3. 动画规范

### 3.1 帧数要求
- **最小帧数**: 8 帧。
- **循环性**: 首尾衔接平滑。

### 3.2 动态细节
- **手部联动**: 手的位置必须随身体起伏或呼吸而变化，带动枪支移动。
- **Idle**: 明显的呼吸（头部/身体上下移动），手部随之上下。
- **Run**: 身体明显的波浪式起伏，手部有摆动。
- **Roll**: 8方向翻滚（或简化为旋转，但需配合朝向）。

## 4. 目录结构规范

```
src/assets/characters/player/
├── PlayerIdle.js  // 包含 5 个方向的 Idle 序列
├── PlayerRun.js   // 包含 5 个方向的 Run 序列
└── PlayerRoll.js
```

## 5. 特殊字符映射 (Tech Spec)
- `H`: 手部 (Hand/Holder)，系统会自动提取其坐标作为 Gun Anchor。渲染时通常使用皮肤色或手套色。
