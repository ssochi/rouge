# 敌人设计文档：腐烂僵尸 (Rotten Zombie)

## 1. 概述
本文档详细描述了游戏中首个正式敌人“腐烂僵尸”的设计规范、行为逻辑及开发计划。该敌人将替换目前游戏中的占位方块，拥有完整的动画表现和攻击交互。

## 2. 视觉规范 (Visual Specs)

遵循 `docs/CHARACTER_GUIDE.md` 2.0 版规范。

*   **尺寸**: 32x32 像素网格。
*   **视角**: 侧视 (Side View)，支持镜像翻转。
*   **风格**:
    *   **配色**: 腐烂的绿色/灰褐色皮肤，暗红色的血迹，破烂的衣物（灰/蓝）。
    *   **特征**: 肢体扭曲，可能露出骨头，行走姿势蹒跚。
    *   **头部**: 表情狰狞，空洞的眼神或发光的红眼。

### 2.1 动画序列 (Animations)
所有动画至少 8 帧。

1.  **Idle (待机)**:
    *   身体不规则抽搐或沉重的呼吸。
    *   手臂自然下垂或微微抬起（渴望抓挠）。
2.  **Run (移动)**:
    *   蹒跚的步伐，甚至拖着一条腿。
    *   身体明显的起伏（波浪式）。
3. **Attack (攻击)**:
    *   **近战挥击**: 抬手 -> 猛烈挥下/抓挠 -> 收招。
    *   **表现**: 简单的单臂或双臂挥击动作。
    *   需要在动画中体现“力量感”和“前摇”。
4.  **Hit (受击)**:
    *   身体瞬间变白或向后仰。
    *   **击退**: 受到攻击时向反方向产生位移 (Knockback)。
    *   少量像素碎片（血肉）飞溅粒子效果（程序实现）。
5.  **Death (死亡)**:
    *   身体散架或倒地化为一滩血水。

## 3. 行为逻辑 (Behavior & AI)

*   **状态机**:
    *   `IDLE`: 玩家不在视野/感知范围内时，随机游荡或原地发呆。
    *   `CHASE`: 发现玩家后，直线或寻路追踪玩家。
    *   `ATTACK`: 进入攻击范围（如 20px）后，触发攻击动画。
    *   `COOLDOWN`: 攻击后的短暂硬直。

*   **攻击机制**:
    *   **类型**: 近战 (Melee)。
    *   **伤害**: 固定数值 (例如 10点)。
    *   **判定**: 在攻击动画的关键帧（如第 4-5 帧）检测前方矩形区域是否有玩家。
    *   **冷却**: 每次攻击后有 1-2 秒冷却时间。

## 4. 系统集成 (System Integration)

### 4.1 玩家受伤与死亡
*   **受伤反馈**:
    *   玩家 HP 扣除。
    *   UI 血条更新 (已有的 `UIManager.updatePlayerStatus`)。
    *   玩家受击闪烁/击退效果 (Knockback)。
*   **死亡处理**:
    *   当 HP <= 0。
    *   触发 `GAME OVER` 状态。
    *   **结算界面**: 弹出“YOU DIED”结算界面，包含重试按钮。

### 4.2 文件结构规划
新增/修改以下文件：

```
src/
  assets/
    characters/
      enemies/
        zombie/
          ZombieIdle.js    # 待机动画数据
          ZombieRun.js     # 移动动画数据
          ZombieAttack.js  # 攻击动画数据
  core/
    entities/              # 新增目录，用于存放具体实体类
      Enemy.js             # 敌人基类 (处理通用逻辑)
      Zombie.js            # 僵尸具体实现 (继承 Enemy)
  ui/
    GameOverScreen.js      # (可选) 简单的死亡结算界面
```

## 5. 开发计划 (Roadmap)

1.  **Phase 1: 资源制作**
    *   绘制 `ZombieIdle.js` 和 `ZombieRun.js`。
    *   在 `Assets.js` 中注册并生成 Sprite。

2.  **Phase 2: 实体类封装**
    *   创建 `Enemy` 基类和 `Zombie` 类。
    *   在 `Game.js` 中替换旧的 `spawnEnemy` 逻辑，实例化 `Zombie` 对象。

3.  **Phase 3: 行为与攻击**
    *   实现追踪 AI。
    *   实现攻击动画与伤害判定。
    *   实现玩家受击扣血与 UI 同步。

4.  **Phase 4: 死亡系统**
    *   实现玩家死亡逻辑。
    *   添加简单的游戏重启功能。
