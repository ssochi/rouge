# 猎人敌人 (Hunter Enemy) 设计文档

## 1. 概述
猎人 (Hunter) 是一种高标准的人形敌人，具备远程攻击能力。与只会近战冲锋的丧尸不同，猎人会试图与玩家保持距离，使用手枪进行射击，并具备基本的战术行为。

## 2. 美术规范 (Visuals)

遵循 `docs/CHARACTER_GUIDE.md` 标准。

- **尺寸**: 32x32 像素网格。
- **风格**: 废土猎人风格。
  - **头部**: 戴着兜帽或防毒面具，眼神锐利。
  - **身体**: 穿着轻型战术背心，便于移动。
  - **腿部**: 战术长裤和军靴。
- **配色**: 以土黄色、深绿色和灰色为主，融入环境但具备识别度。
- **动画**:
  - **Idle**: 持枪警戒，轻微呼吸起伏。
  - **Run**: 战术移动，持枪奔跑。
  - **Shoot**: 抬手射击动作（或由 IK 手部系统接管）。

## 3. 行为逻辑 (AI Behavior)

猎人具备有限状态机 (FSM) AI：

### 3.1 状态定义
1. **Idle (待机)**: 原地警戒或小范围巡逻。
2. **Chase (追击)**: 当玩家进入视野但超出射程时，向玩家移动。
3. **Combat (战斗)**: 当进入有效射程时：
   - **保持距离**: 如果玩家太近，试图后退（放风筝）。
   - **瞄准**: 锁定玩家位置，有短暂的瞄准延迟。
   - **射击**: 发射子弹。
4. **Flee (逃跑)**: (可选) 血量过低时试图寻找掩体或远离玩家。

### 3.2 感知系统
- **视距**: 比丧尸更远 (e.g., 400px)。
- **听觉**: 响应枪声。

## 4. 战斗系统 (Combat)

### 4.1 武器：敌人手枪 (Enemy Pistol)
- **外观**: 类似于玩家的手枪，但可能颜色较深。
- **挂载**: 使用简化版的 `HandSystem` 或直接在 Sprite 上绘制持枪手臂（推荐复用 `HandSystem` 逻辑或简化版 IK，以实现准确的瞄准朝向）。
  - *技术决策*: 为了效果酷炫且准确，猎人将拥有独立的 `EnemyHandSystem`，支持枪械跟随目标旋转。

### 4.2 射击参数
- **射速**: 较低 (e.g., 1.5秒/发)，给玩家躲避空间。
- **弹道**:
  - **速度**: 中等 (e.g., 8px/frame)，玩家可通过翻滚或走位躲避。
  - **颜色**: 红色或橙色 (`#e74c3c`)，与玩家子弹区分。
  - **伤害**: 10-15 点。
- **预警**: 射击前枪口会有短暂的红色瞄准线或聚光特效，提示玩家即将开火。

## 5. 技术实现方案

### 5.1 文件结构
- `src/core/entities/Hunter.js`: 猎人实体类，继承自 `Enemy`。
- `src/assets/characters/enemies/hunter/`:
  - `HunterIdle.js`
  - `HunterRun.js`
  - `HunterSprite.js` (Avatar)
- `src/core/systems/EnemyHandSystem.js`: (可选) 处理敌人持枪瞄准逻辑。

### 5.2 核心逻辑 (`Hunter.js`)
- **Update Loop**:
  - 检查与玩家距离。
  - 根据状态更新移动向量（使用 `NavigationGrid` 避障）。
  - 更新 `EnemyHandSystem` 瞄准角度。
  - 处理射击冷却与触发。
- **Draw Loop**:
  - 绘制身体（根据移动方向翻转）。
  - 调用 `EnemyHandSystem` 绘制武器（层级需处理：朝右时在身前，朝左时在身前，背对时在身后？通常 2D Top-down 枪始终在身前或根据层级排序）。

### 5.3 弹道处理
- 复用 `CombatSystem`。需修改 `bullets` 数组结构或 `updateBullets` 逻辑，增加 `source` 字段 (`player` | `enemy`) 以避免友军伤害（猎人不打猎人，猎人打玩家）。
- 或者：`CombatSystem` 区分 `playerBullets` 和 `enemyBullets`。

## 6. 开发计划
1. **美术资源**: 创建猎人像素画模板。
2. **核心类**: 实现 `Hunter` 类与基础 AI 移动。
3. **武器系统**: 实现敌人持枪与瞄准逻辑。
4. **射击逻辑**: 扩展战斗系统支持敌对子弹。
5. **集成测试**: 在地图中生成猎人并测试战斗体验。
