# 地牢房间与视觉全面重设计方案

> 状态：R1-R4 已完成（feature/dungeon-overhaul 分支）。视觉方向经用户确认为「干净大色块」，全程截图自查迭代。
> 日期：2026-07-05
> 背景：P5 完成后试玩反馈——小地图丑、墙面/地面丑、整体太暗、房间只是杂物堆砌没有关卡概念、持枪敌人太强掩体太少容易死。本方案对地牢的视觉素材与关卡结构做整体返工。
> 范围：视觉重制 + 遭遇战房间系统 + 战斗平衡。P4 剩余项（6 新敌人/词缀/Boss 整合）顺延，完成本方案后回归，新敌人产出后直接进入遭遇战模板角色池。

---

## 1. 问题诊断

| 反馈 | 根因分析 |
|---|---|
| 墙很丑 | 墙顶 16×8 砌体网格过密、高光碎、颜色饱和度低对比弱，整面墙糊成"脏灰"；前脸只露 16px 全是勾缝 |
| 地面很丑 | 16px 子瓦两行砖 + 逐瓦噪点 → 高频颗粒重复，看着"花" |
| 非常暗 | 环境光压到 62~86/255（默认 115），火把半径 122 覆盖不足，房间中央大片死黑 |
| 小地图丑 | 拓扑节点图（圆点+连线）信息对但观感简陋，和游戏画面割裂 |
| 没有关卡概念 | 敌人=深度池随机撒、掩体=随机撒、装饰=随机撒，三者互不知晓；房间不构成任何战术情境 |
| 枪兵太强 | hunter/soldier 用真实武器，攻速快弹速快；掩体随机可能一个没有；进房锁门瞬间被集火 |

核心结论：**素材要"减噪提对比"，关卡要"敌人+掩体+地形一体设计"**。

## 2. 视觉重制（干净大色块方向，参照挺进地牢）

设计原则：像素风的"好看"来自大色块 + 强明暗交界 + 低噪点，而不是细密纹理。

1. **墙体重画**（`DungeonWallSprites.js` 全部重做）
   - 墙顶：近乎纯色大平面 + 外缘 1px 亮轮廓线 + 内侧 1px 暗压边，砌缝改为稀疏大砖（32×16 一 tile 只切一刀），去掉碎高光。
   - 前脸：两排大砖（16×8/砖），深色 1px 勾缝，顶部一条强亮檐线，底部 2px 接地暗带；变体只做「完好/一处缺角/一撮苔藓」低频差异。
   - 主题色板整体提饱和提对比（顶面明显亮于前脸 ≥25% 亮度差）。
2. **地面重画**（`DungeonFloorSprites.js` 重做）
   - 改为 32×32 大石板（跨整 tile），一 tile 一块板 + 1px 暗缝；板面近纯色，仅 2~3 像素低频色斑；四变体 = 微亮/微暗/细裂/整洁。
   - 贴花保留但降密度（每房 2-5 → 1-3），贴花对比降低（融入地面）。
3. **亮度校准**
   - 环境光提到 F1 {100,104,116} / F2 {98,110,100} / F3 {112,100,96} 量级（≈默认亮度 90~95%，色调保留但不再压黑）。
   - 火把：radius 122→150、intensity 0.85→0.95；火盆 radius 146→180。黑暗是氛围层，不再影响可读性。
4. **小地图重绘**（`Renderer.drawDungeonMinimap`）
   - 拓扑节点图 → **真实房间形状图**：按房间 rect 等比缩放绘制圆角矩形块，走廊画为连接短线；当前房间高亮描边+呼吸，特殊房内嵌图标（$ / + / !），Boss 房骷髅标。
   - 面板：半透明圆角深底 + 1px 亮边框，右上角常驻但更紧凑；已探索实心、前沿虚框。

## 3. 遭遇战房间系统（关卡核心）

**思路：房间 = 一道设计好的战斗题。** 用字符画手作「遭遇战模板」，同一张图里同时定义地形墙、掩体、出怪点（带角色）、装饰位，三者天然构成战术情境；生成器负责把模板拼进 BSP 拓扑。

1. **模板格式**（`src/core/systems/generation/EncounterTemplates.js`）
   ```
   图例：# 内墙  c 掩体  d 装饰  m 近战出怪  r 远程出怪  h 重装出怪  e 精英出怪  . 空地
   例：「十字火力网」(13×11, mid 档)
   .............
   ..c.......c..
   ......r......
   ..#.......#..
   .....m.m.....
   .r....#....r.
   .....m.m.....
   ..#.......#..
   ......r......
   ..c.......c..
   .............
   ```
   - 每模板：`{id, size, tier(浅/中/深), 威胁轴标签, rows, weight}`；居中放进房间（四周保留 ≥2 tile 通带），房间尺寸不足则回退小一档模板。
   - 首期 **≥15 个遭遇战模板**（浅 5 / 中 6 / 深 4），每个围绕一个战术点子设计：狙击长廊（远程高位+走廊掩体链）、冲脸围栏（近战多+中央环形掩体）、交叉火力（对角远程+中路掩体跳）、绞肉走道（双通道+重装堵口）、暗堡（角落重装+正面掩体阵）等。
   - **掩体保底**：模板含远程出怪点时，玩家入口侧保证 ≥2 个掩体（设计时保证，测试断言）。
2. **角色→敌人映射**：模板只写角色（m/r/h/e），`FloorConfigs` 每层映射具体敌人（F1 m=zombie/female、r=hunter、h=brute；F2/F3 逐层升级），保留楼层缩放。P4 新敌人完成后直接扩充映射表（如 r→warlock、h→shieldbearer），模板无需改动。
3. **生成器接线**：`assignRoomCategories` 后普通战斗房不再走「深度池随机数量 + 随机掩体 + 随机装饰」，改为「按深度档抽遭遇战模板 → 铺墙/掩体/装饰 → 记录出怪点」；`DungeonManager._spawnRoomEnemies` 按出怪点+角色映射生成。特殊房（宝箱/商店/精英/Boss）沿用现有专属模板机制并逐步字符画化。
4. **旧机制处置**：`RoomInteriorTemplates` 的纯地形模板保留给特殊房与兜底；`generateRoomCover/Decor` 随机撒法仅作模板缺失时的回退。

## 4. 战斗平衡（本次一并调）

| 项 | 现值 | 调整 |
|---|---|---|
| hunter 攻速 | fireIntervalMultiplier 2 | → 3.2（约慢 60%） |
| soldier 攻速 | 同源 | → 2.8，且进房首发延迟 45 帧（锁门后有反应时间） |
| 敌人子弹速度 | 武器原值 | 敌人源子弹全局 ×0.75（新乘区，挂 `_pushWeaponProjectiles` enemy 分支） |
| 掩体密度 | 随机 2-7 | 模板保证 + 掩体 HP 上调（box 20→32），远程房入口侧保底 |
| 每房敌人数 | 深度池 4-11 | 模板出怪点决定（浅 3-5 / 中 5-7 / 深 6-8），少而精 |

## 5. 实施分期

| 阶段 | 内容 | 交付 |
|---|---|---|
| ✅R1 视觉重制 | 墙/地面重画（大色块）、亮度校准（含普通房保底火盆）、贴花降密、能量屏障门重绘（用户点名） | 亮、干净、有对比的房间观感 |
| ✅R2 小地图重绘 | 真实房间形状小地图 + 面板美化 | 一眼可读的漂亮小地图 |
| ✅R3 遭遇战系统 | EncounterTemplates 15 + roleMap 角色映射 + 生成器/DungeonManager 接线 + 掩体保底断言 | 每个房间是一道设计好的战斗题 |
| ✅R4 平衡收尾 | 枪兵攻速/弹速/首发延迟、掩体 HP、文档更新 | 打得过、有来回的战斗 |

每阶段：vitest + `npm run build` + 提交。完成后回归 P4 剩余项（新敌人→进角色映射、词缀、Boss 整合）。

## 6. 风险

- 美术方向主观：R1 先重画 F1 一套 + 截图级自查（对比度/噪点指标），不满意可只调色板不动结构。
- 模板适配房间尺寸：模板按尺寸档设计 + 居中放置 + 小一档回退，保证任何 BSP 出的房间都有可用模板。
- 出怪点被玩家站位：出怪点距玩家 < 3 tile 时挪到最近可用点（现 spawnEnemy strict 已有碰撞检查）。
