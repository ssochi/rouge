# Mario 输入流畅度与 WASD 支持

## 背景
- 现象：Mario 在 PixelOS 中操作不流畅，出现“移动时难以跳跃、跳跃时难以移动”的体感。
- 诉求：增加 `WASD` 支持，并提升跳跃与横向移动并行时的手感稳定性。

## 目标
1. 支持 `Arrow` 与 `WASD` 双键位：
   - 左移：`ArrowLeft` / `A`
   - 右移：`ArrowRight` / `D`
   - 跳跃：`ArrowUp` / `W` / `Space`
2. 提升空中与地面切换时的输入响应，避免“断输入”与“粘滞感”。

## 实施范围
- `src/pixelOS/apps/MarioApp.js`
- `docs/TECH_OVERVIEW.md`

## 方案

### 1) 统一按键映射（Arrow + WASD）
- `onKeyDown/onKeyUp` 中统一对 `key.toLowerCase()` 分支处理。
- 让 `W/A/S/D` 与方向键共享同一套内部状态机。

### 2) 输入与手感稳定化
- 使用持续按下布尔状态，不再依赖按键超时模拟。
- 增加 `jump buffer`（跳跃输入缓冲）：
  - 玩家稍早按跳，落地后仍可触发跳跃。
- 增加 `coyote time`（离地容错帧）：
  - 刚离开平台的短时间内仍可起跳。
- 增加空中控制参数：
  - `AIR_ACCEL` / `AIR_DECEL` 与地面参数分离，减少空中“刹停突兀”。
- 双向同时按下时，使用“最后水平输入方向”作为优先方向，避免互相抵消导致停顿。

## 验证点
1. `A/D` 与方向键都可稳定移动。
2. `W/Space/ArrowUp` 都可跳跃。
3. 在按住移动的同时起跳，空中仍保持平滑横向控制。
4. 从平台边缘离地时，短时间内按跳仍可起跳（容错生效）。
