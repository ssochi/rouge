# 程序化鱼缸动画特性

## 概述

为了提升游戏环境的生动性，我们将原本的帧动画鱼缸（`FishTankSprite.js`）升级为程序化动画鱼缸（`FishTankObject.js`）。新的鱼缸包含动态的鱼群、摇曳的水草、上升的气泡以及水面和玻璃的光影效果，所有这些都是在运行时实时计算和绘制的。

## 实现细节

### 1. 静态背景 (`FishTankSprite.js`)

`FishTankSprite.js` 现在只负责生成鱼缸的静态部分，以减少每帧的绘制开销。
- **柜子 (Cabinet)**: 木质纹理，带有门和把手。
- **玻璃框 (Glass Frame)**: 鱼缸的边框。
- **背景水 (Background Water)**: 深蓝色的静态背景。
- **沙底 (Sand)**: 鱼缸底部的沙层。

这些静态元素被缓存为一个 Canvas 对象，在 `FishTankObject.draw` 中作为底层绘制。

### 2. 动态逻辑 (`FishTankObject.js`)

所有的动画逻辑都封装在 `FishTankObject` 的 `update` 和 `draw` 方法中。

#### 数据结构
每个鱼缸实例维护一个 `fishTank` 状态对象：
- `time`: 全局时间累加器，用于驱动正弦波动画。
- `fish`: 鱼的数组，每条鱼包含位置、速度、方向、颜色、大小和摆动相位。
- `weeds`: 水草数组，包含位置、高度、颜色和摆动相位。
- `bubbles`: 气泡数组，包含位置、速度和摆动参数。

#### 动画行为
- **鱼 (Fish)**:
  - **移动**: 在鱼缸范围内左右游动，碰到边界自动转向。
  - **摆动**: 身体上下微调（Bobbing），尾巴根据正弦波左右摆动。
  - **外观**: 简单的椭圆身体 + 动态三角形尾巴 + 眼睛像素。
- **水草 (Weeds)**:
  - 使用二次贝塞尔曲线 (`quadraticCurveTo`) 绘制。
  - 控制点根据 `Math.sin(time)` 进行摆动，模拟水流效果。
- **气泡 (Bubbles)**:
  - 随机生成，从底部上升。
  - 上升过程中伴随左右摇摆（Wobble）。
  - 到达水面后消失。
- **光影 (Lighting)**:
  - **水面**: 一条随时间微弱波动的白色线条。
  - **玻璃反光**: 静态的斜向高光，覆盖在所有动态元素之上，增加玻璃质感。

### 3. 性能优化

- **裁剪 (Clipping)**: 使用 `ctx.clip()` 确保鱼和气泡不会绘制到鱼缸边框之外。
- **分层绘制**: 
  1. 静态背景 (Sprite)
  2. 水草 (动态)
  3. 鱼 (动态)
  4. 气泡 (动态)
  5. 玻璃反光 (静态/叠加)

## 使用方法

鱼缸作为一种家具 (`furniture`)，可以像其他物体一样放置。
- **类型**: `fish_tank`
- **尺寸**: 32x32
- **交互**: 可破坏（有 HP 和 Hitbox）。

## 未来改进

- **交互**: 玩家靠近时鱼群可能会惊散。
- **破损**: 鱼缸被打破时，水流出，鱼在地上跳动（目前鱼缸打破后只是变为通用碎片）。
