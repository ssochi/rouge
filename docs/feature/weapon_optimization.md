# 武器优化方案

## 1. 概述
本着提升游戏视觉体验和手感的目标，针对近期新增的五把武器进行优化。重点针对 SMG、Sniper、Crossbow 的美术表现进行重绘，并修正榴弹发射器（Cannon）的弹道逻辑及移除弩箭的穿透特性。

## 2. 视觉优化 (Visual Improvements)

### 2.1 SMG (Weapon 6)
- **状态**: 保持现状 (No Change)。
- **备注**: 用户反馈目前效果尚可，暂不修改。

### 2.2 Sniper (Weapon 7)
- **当前问题**: 造型生硬，缺乏高级感，且缺乏瞄准辅助。
- **优化方案**:
  - **新增红点瞄准器 (Red Dot Sight)**: 在枪身上方添加明显的红点瞄准镜结构。
  - **激光辅助线 (Laser Sight)**: 在游戏中实现可见的红色激光射线，帮助玩家预判射击路径。
  - 优化枪身线条，使其更加修长、流线型。
  - 细化枪口制退器 (Muzzle Brake) 的细节。

### 2.3 Crossbow (Weapon 8)
- **当前问题**: 结构怪异，可能看起来像玩具。
- **优化方案**:
  - 重绘弓臂 (Limbs)，使其在视觉上更有张力（弯曲度）。
  - 优化弩身 (Rail) 和 弩托 (Stock) 的比例。
  - 强化箭矢 (Bolt) 的视觉表现，使其看起来更有杀伤力。
  - 调整配色，使用更写实的复合材料颜色（黑/灰/迷彩）。

## 3. 逻辑优化 (Logic Improvements)

### 3.1 榴弹发射器 (Cannon/Grenade Launcher)
- **当前问题**: 弹道逻辑在 2D 俯视角下表现错误。目前的重力逻辑导致子弹向屏幕下方（南）坠落，看起来像“拐弯”，而不是垂直高度上的下坠。
- **优化方案**:
  - **实现伪 3D 高度系统 (Fake Height System)**:
    - 引入 `z` (高度) 和 `vz` (垂直速度) 属性。
    - 逻辑层：投射物在 (x, y) 平面上做匀速直线运动，在 (z) 轴上做抛物线运动 (`vz -= gravity`)。
    - 渲染层：绘制时，投射物的 Y 坐标 = `y - z` (模拟高度视觉差)，同时在 `(x, y)` 处绘制一个圆形阴影以标示实际落地位置。
    - 碰撞判定：当 `z <= 0` (落地) 时触发爆炸。
  - 调整参数以获得良好的手感（初速、重力加速度）。

### 3.2 Crossbow
- **当前问题**: 穿透逻辑怪异 (Penetration logic is weird)。
- **优化方案**:
  - 移除 `piercing: 1` 属性。弩箭将不再穿透敌人，改为单体高伤害或附带击退效果。
