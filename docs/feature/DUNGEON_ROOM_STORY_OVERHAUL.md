## 故事主线

小镇地下埋着一座旧监狱——**深渊监狱**。几十年前它明面上关押重刑犯，暗地里狱方与一支研究团队合作，用囚犯做"强化实验"。实验失控引发暴动，设施被整体封锁废弃。

多年后，邪教**裂渊会**找到了入口。他们把监狱中层改造成圣殿，以"深渊之声"为名招募信徒——实际上是被最深处实验区里未死之物的低语所蛊惑。玩家从传送门闯入，逐层深入，揭开三层递进的真相：

- **表层真相（F1）**：这里发生过越狱与屠杀，狱卒至死仍在"值守"。
- **中层真相（F2）**：邪教不是主人，是被引来的祭品。
- **深层真相（F3）**：一切的源头是当年的实验——以及那台没造完的"看守者"。

## 技术能力（基建已就位）

1. **楼层亲和**：模板加 `floors: [N]` 只在 N 层出现（encounters/f1_prison.js 等按层拆分，每个 agent 独占一个文件）。
2. **每房间地板**：模板加 `floorType: 'XXX'`（FLOOR_TYPES 键名）整房换地板。新地板类型走：FloorTypes.js 注册 id+key → FloorPalette.js 配色 → FloorSprites.js PixelDraw 变体。**ID 预分配**：F1 用 10-12、F2 用 13-15、F3 用 16-18，避免冲突。
3. **异形房间**：字符画中用 `#` 成块雕刻即可做出 L 型/T 型/环形/十字等任意形状（`#` 是实体内墙，测试保证不封死连通）。
4. **物件**：legend 字符 → ObjectRegistry 物件名。新家具走 OBJECT_CREATION_GUIDE.md 管线（PixelDraw 绘制 → Assets 注册 → ObjectRegistry 注册）。
5. **尺寸/健全性约束**：以 tests/encounter-templates.test.js 为准（连通性 BFS、远程房掩体≥2、行宽一致等）。
6. **波次**：小写 m/r/h/e 波1（热身 3-5 只）、大写 M/R/H/E 波2（上强度 ≥波1）。
