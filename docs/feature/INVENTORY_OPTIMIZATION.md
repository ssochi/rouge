# 背包系统优化与交互方案

## 1. 目标
优化现有背包系统的用户体验（UX）与视觉表现（UI），并完善物品在世界中的交互（丢弃与拾取）。目标是打造一个符合复古像素风格、操作流畅且直观的背包系统。

## 2. 视觉优化 (Visual Improvements)

### 2.1 UI 风格统一
*   **色调**: 保持深蓝灰色调 (`#2c3e50`, `#34495e`)，增强像素风格边框（双层边框，内凹/外凸效果）。
*   **字体**: 继续使用 `Press Start 2P`，但对正文文本（如 Tooltip 描述）使用更易读的像素等宽字体（如 `Courier New` 或像素风格变体）。
*   **槽位设计**:
    *   **空槽位**: 添加低透明度的背景图案（如斜线或内阴影），增加深邃感。
    *   **选中/悬停**: 增加高亮边框呼吸效果，或槽位背景色略微变亮。
    *   **物品图标**: 统一缩放比例，确保像素不失真（`image-rendering: pixelated`）。

### 2.2 动画与反馈
*   **窗口动画**: 保持现有的 `popIn` 效果，增加关闭时的 `fadeOut`。
*   **交互反馈**: 点击槽位时增加微小的缩放或下沉动画（`active` 态）。
*   **Tooltip**: 
    *   跟随鼠标，但在屏幕边缘自动调整位置防止溢出。
    *   展示内容：物品名称（稀有度颜色）、类型、详细描述、属性数值（如武器伤害）、操作提示（左键/右键/Shift）。

## 3. 交互优化 (Interaction UX)

### 3.1 鼠标操作逻辑 (参考主流沙盒游戏)
| 操作 | 鼠标状态 | 目标槽位状态 | 行为 |
| :--- | :--- | :--- | :--- |
| **左键** | 空 | 有物品 | **拿起** (全部) |
| **左键** | 有物品 | 空 | **放置** (全部) |
| **左键** | 有物品 | 相同物品 | **堆叠** (直到上限) |
| **左键** | 有物品 | 不同物品 | **交换** |
| **右键** | 空 | 有物品 | **拆分** (拿走一半) |
| **右键** | 有物品 | 空 | **放置一个** |
| **右键** | 有物品 | 相同物品 | **堆叠一个** |
| **Shift+左键** | 任意 | 任意 | **快速转移** (背包 <-> 快捷栏) |

### 3.2 丢弃逻辑 (Drop)
*   **触发方式**: 
    1. 鼠标抓取物品后，点击背包窗口外部区域。
    2. (可选) 选中物品后按 `Q` 键丢弃（需新增快捷键支持）。
*   **表现**:
    *   物品从玩家位置“抛出”，带有简单的抛物线动画。
    *   生成 `DroppedItem` 实体。

## 4. 世界交互 (World Interaction)

### 4.1 拾取系统 (Pickup)
*   **交互方式**: 
    *   **按键拾取**: 靠近物品时，显示交互提示（如 "Press E to pick up [Rifle]"），按下 `E` 键拾取。
    *   **自动吸附 (可选)**: 对于金币或特定材料，可增加磁力吸附效果。
*   **反馈**:
    *   拾取成功后，播放简短音效（如有）。
    *   屏幕左侧或角色头顶弹出浮动文字：`+1 Rifle`。

### 4.2 掉落物视觉 (Dropped Item)
*   **悬浮动画**: 物品在地面上方轻微上下浮动。
*   **阴影**: 物品下方绘制椭圆形阴影，增强空间感。
*   **描边**: 为掉落物 sprite 增加白色描边（Outline），使其在复杂背景中更显眼。

- [ ] 优化 `DroppedItem` 渲染（增加描边/发光）。

## 6. 预期效果
玩家能够流畅地管理背包，直观地了解物品信息，并在游戏世界中自然地丢弃和交换物品。
