# 像素画程序化绘制指南 (Procedural Pixel Art Guide)

本文档总结了在 `BreakableObjects` 和 `PlayerGenerator` 重构过程中沉淀的像素画绘制经验，特别是如何使用代码 (`PixelDraw`) 替代静态素材数组，以实现更高质量、更具透视感和细节的 2.5D 像素风格。

## 1. 核心理念

*   **程序化 (Procedural)**: 摒弃硬编码的字符数组 (`char[][]`)，改用 Canvas API 进行绘图。这允许我们方便地调整尺寸、颜色、形状，并复用绘制逻辑。
*   **矢量化思维 (Vector Thinking)**: 虽然最终输出是像素，但绘制过程应基于“路径”和“形状”。避免一个像素一个像素地画，而是画矩形、圆、多边形和曲线。
*   **透视优先 (Perspective First)**: 严格遵循 Top-Down 35度视角。物体必须有清晰的 **顶面 (Top Face)** 和 **正面 (Front Face)**。
*   **动态与物理 (Dynamics & Physics)**: 程序化生成的最大优势在于动画。可以通过参数控制头发、衣物等软体部位的物理摆动，而非绘制多帧静态图。
*   **拒绝僵硬 (No Stiffness)**: 避免完美的直线和矩形。利用微小的偏移、切角、磨损和曲线来模拟真实物体的有机感。

## 2. 工具库: PixelDraw

我们封装了 `src/utils/PixelDraw.js`，提供了类似 SVG 的绘图接口，但针对像素画进行了优化（禁用抗锯齿）。

### 常用 API

*   `rect(x, y, w, h, color)`: 基础构建块。
*   `line(x1, y1, x2, y2, color)`: 绘制任意两点间的直线。
*   `fillPath(points, color)`: **核心**。绘制任意多边形。用于打破矩形限制，绘制不规则形状、梯形、切角等。
    ```javascript
    drawer.fillPath([
        {x: 10, y: 10}, {x: 20, y: 10},
        {x: 22, y: 20}, {x: 8, y: 20}
    ], color);
    ```
*   `fillQuadCurve(startX, startY, cpX, cpY, endX, endY, color)`: **神器**。绘制二次贝塞尔曲线填充区域。用于表现圆润的物体（如木桶、花瓶）或头发的自然弧度。
*   `strokePath(points, color)`: 描边/画线。用于绘制高光线、装饰带。

## 3. 绘制技法指南
在 35度俯视角下，表现体积感的关键在于：

1.  **顶面与正面的比例**: 顶面通常可见，且高度被压缩。例如一个立方体，顶面高度可能是正面的 1/2 或 1/3。
2.  **圆形物体的透视**:
    *   **顶面**: 必须是 **椭圆**，而非正圆。
    *   **侧面**: 轮廓线应为曲线。
    *   **底部**: 底部边缘的弧度应比顶部边缘 **更弯曲**（因为离视线更远，透视变形更大，或者仅仅为了视觉稳重感）。
3.  **高光与阴影**:
    *   **光源**: 默认假设光源来自左上方。
    *   **高光**: 出现在物体左侧边缘、顶面边缘。
    *   **阴影**: 出现在物体右侧、底部、以及凹陷处。使用半透明黑色 (`rgba(0,0,0,0.2)`) 叠加，而非硬编码深色。
### 3.1 角色生成 (Character Generation)

角色绘制的核心是将各个部位模块化，并支持参数化变形。

*   **头部 (Head)**:
    *   **分层**: 后发 (Back Layer) -> 脸型 -> 五官 -> 前发 (Front Layer)。
    *   **头发物理**: 使用正弦波 (`Math.sin`) 计算发梢的 X 轴偏移，模拟风吹效果。
    *   **大头比例**: 头部宽度通常占身体宽度的一半以上 (Chibi Style)，以容纳更多表情细节。
*   **身体 (Body)**:
    *   **衣物动态**: 对于长款衣物（如风衣），根据角色运动方向计算衣摆的滞后（Lag）或摆动（Swing）。
    *   **叠加顺序**: 腿部 (Back Leg) -> 身体/衣物 -> 腿部 (Front Leg)。注意遮挡关系。
*   **腿部 (Legs)**:
    *   不要画死矩形。根据动作状态（跑、跳、蹲）动态绘制大腿和小腿的像素位置。

### 3.2 告别“方盒子” (Breaking the Box)

*   **切角 (Chamfering)**: 不要画完美的 90 度直角。使用 `clearRect` 或 `fillPath` 切掉 1-2 个像素的角，使物体看起来有磨损感。
*   **轮廓微调**: 木箱的边缘不要画成一条直线。可以断开，或者在中间稍微向内/向外偏移 1 像素。
*   **曲线建模**: 对于木桶、罐子，使用 `fillQuadCurve` 替代“堆叠不同宽度的矩形”。
    *   *Bad*: 矩形堆叠会产生明显的阶梯感。
    *   *Good*: 贝塞尔曲线能生成平滑的边缘像素排列。

### 3.3 细节与质感 (Details & Texture)

*   **木纹**: 使用 `hLine` 或 `pixel` 绘制断续的水平/垂直线。不要画满，点到为止。
*   **金属感**:
    *   高光必须锐利（白色或亮色）。
    *   金属箍应跟随物体的透视弧度（使用 `strokePath` 配合正弦波或贝塞尔曲线计算坐标）。
*   **磨损 (Wear & Tear)**:
    *   在边缘随机擦除像素。
    *   使用浅色半透明像素 (`rgba(0,0,0,0.15)`) 绘制表面的污渍或划痕。

*   **亚像素动画 (Sub-pixel Animation)**: 在绘制时，允许坐标出现小数（如 y=22.5）。虽然最终渲染会取整，但在连续动画（如呼吸）中，利用 `Math.floor` 或 `Math.round` 的阈值特性，可以产生比 1px 更细腻的“跳动”感，或者通过灰度/透明度模拟亚像素（目前主要依靠位置取整）。
*   **高光**:
    *   墨镜、金属必须有纯白 (`#ffffff`) 高光点。
    *   头发需有高光带 (`Highlight Band`)。

## 4. 实例分析

### 角色风衣 (Trench Coat)
*   **建模**: 分为左片、右片、领子、后摆四个部分绘制。
*   **动画**: 奔跑时，后摆的底部坐标 `x` 加上 `Math.sin(time) * amplitude`，产生飘逸感。

### 木桶 (Barrel)
*   **形状**: 使用左右两条对称的贝塞尔曲线 (`fillQuadCurve`) 构建鼓起的桶身。
    *   左半边: `(cx, topY) -> (cx - wMid/2, midY) -> (cx, bottomY)`
    *   右半边: `(cx, topY) -> (cx + wMid/2, midY) -> (cx, bottomY)`
*   **金属箍 (Metal Bands)**: 为了表现圆柱体的透视，金属箍不能画成直线。
    *   使用 `fillPath` 绘制一个弯曲的带状多边形。
    *   计算公式: `y = base_y + cos((t - 0.5) * PI) * curvature`，其中 `t` 从 0 到 1。中间 (t=0.5) 凸起，两端下垂。
*   **顶面细节**:
    *   绘制椭圆作为开口 (`ellipse`)。
    *   在椭圆下半部分绘制高光像素，模拟木板边缘的反光。

### 木箱 (Box)
*   **非矩形轮廓**: 即使是方形木箱，也使用 `fillPath` 定义四个角，允许微小的随机偏移或切角，打破数字生成的完美感。
*   **透视面**:
    *   **正面 (Front Face)**: 颜色较深 (`cDark`)。
    *   **顶面 (Top Face)**: 颜色较浅 (`cBase`)，高度约为正面的 1/3。
*   **细节**:
    *   **X型加固条**: 在侧面使用多边形绘制交叉的木条。
    *   **钉子**: 在角落点缀高对比度的金属色像素 (`cNail`)。
    *   **木纹**: 使用 `vLine` 在顶面绘制断续的竖线。

### 花瓶 (Vase)
*   **复合曲线**: 组合多个贝塞尔曲线段（底座 -> 瓶身 -> 瓶颈 -> 瓶口）。
    *   瓶身使用 `fillQuadCurve` 向外鼓起。
    *   瓶颈使用 `fillPath` 向内收缩。
*   **装饰纹理 (Zigzag Pattern)**:
    *   利用数学公式生成之字形路径。
    *   关键点: 纹理带必须跟随瓶身的球体透视。即中间部分的 Y 坐标要比边缘低（呈现“笑脸”弧度）。
    *   公式: `y += Math.pow((i - steps/2)/(steps/2), 2) * curvature`。

## 5. 总结

使用代码绘制像素画看似繁琐，实则带来巨大的灵活性。我们可以通过调整参数瞬间改变物体的宽窄、高矮，甚至批量生成不同变体。核心在于**掌握 `PixelDraw` 的矢量绘图能力**，并时刻保持**透视意识**和**动态思维**。
